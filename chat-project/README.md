# Realtime Chat Engine

A real-time communication engine built with Python and WebSockets.

The project provides a modular structure for managing users, rooms and message communication through asynchronous connections.

## Features

- WebSocket-based real-time communication
- User connection management
- Room creation and management
- User join and leave operations
- Custom message protocol
- Event handlers
- Asynchronous architecture using asyncio

## Architecture

The project follows a modular architecture where each component has a specific responsibility.
